🚀 Sobel Edge Detection

Reveal the Hidden Edges in Any Image!

🤔 What Is Edge Detection?

  • Finds where pixel intensity changes sharply
  • Helps detect shapes, borders, and objects
  • Used in self-driving cars, medical imaging, inspection, and more

🎯 Meet the Sobel Operator

A simple 3×3 filter to detect image gradients

Sobel X:
[-1  0  1]
[-2  0  2]
[-1  0  1]
Sobel Y:
[-1 -2 -1]
[ 0  0  0]
[ 1  2  1]

🔍 How It Works

  • Slide the kernel over the image
  • Measure change in intensity
  • High change = Edge

🧮 Numerical Example

3×3 patch:

[100 100 100]
[150 150 150]
[200 200 200]

Sobel Y → |G| = √(0² + 400²) = 400

📐 Horizontal vs Vertical Edges

Sobel X → vertical edges
Sobel Y → horizontal edges

💻 Python in 3 Lines

import cv2
sx = cv2.Sobel(img, cv2.CV_64F, 1, 0)
sy = cv2.Sobel(img, cv2.CV_64F, 0, 1)
mag = cv2.magnitude(sx, sy)

⚖️ Sobel vs Others

  • Sobel – Balanced, smooth
  • Prewitt – Simpler, noisier
  • Scharr – High accuracy
  • Canny – Clean but complex
