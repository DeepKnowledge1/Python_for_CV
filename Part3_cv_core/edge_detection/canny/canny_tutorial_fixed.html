Step 3: Non-Maximum Suppression

This step thins thick edges by keeping only the pixels with maximum gradient magnitude along the gradient direction. This creates thin, well-defined single-pixel-wide edges.

Why is this needed?

After gradient calculation, edges are often thick bands of high-magnitude pixels. We need to thin them to single-pixel lines for precise edge detection.

Before Suppression

Thick edges with multiple high-magnitude pixels

After Suppression

Thin, single-pixel-wide edges

Detailed Algorithm:

Step 1: For each pixel, determine its gradient direction

Step 2: Round the direction to one of four angles:

  • 0° (Horizontal): Compare with left and right neighbors
  • 45° (Diagonal /): Compare with top-right and bottom-left neighbors
  • 90° (Vertical): Compare with top and bottom neighbors
  • 135° (Diagonal \): Compare with top-left and bottom-right neighbors

Step 3: Keep pixel only if its magnitude is greater than both neighbors along the gradient direction

Pseudocode:
For each pixel (i,j):
  direction = gradient_direction[i][j]
  magnitude = gradient_magnitude[i][j]
  neighbor1, neighbor2 = get_neighbors_along_direction(direction)
  if magnitude >= neighbor1 AND magnitude >= neighbor2:
    keep pixel
  else:
    suppress pixel (set to 0)

Numerical Example:

Consider a pixel with:

  • Gradient magnitude = 150
  • Gradient direction = 0° (horizontal edge)
  • Left neighbor magnitude = 120
  • Right neighbor magnitude = 140

Decision: Since 150 > 120 AND 150 > 140, keep this pixel


Another pixel with:

  • Gradient magnitude = 130
  • Gradient direction = 0° (horizontal edge)
  • Left neighbor magnitude = 140
  • Right neighbor magnitude = 125

Decision: Since 130 < 140, suppress this pixel (set to 0)

Key Benefits:
• Precision: Edges become single-pixel lines instead of thick bands
• Localization: Edge positions are more accurate
• Noise Reduction: Eliminates weak edge responses near strong edges
• Preparation: Sets up clean input for the thresholding step
